# 笔记格式：模板、范例、反例

## 模板（复制后填）

> 条目层级跟着上一级走：上层是 `###` 主题时条目用 `####`；下面示例直接挂在 `##` 下，所以是 `###`。

```markdown
#### 知识点名称
一到三句话说清定义或结论，不看上文也能读懂。

$$
<公式，没有就删掉这段>
$$

- **符号**：$符号$ —— 含义、单位；$符号2$ —— 含义、单位。
- **条件**：适用前提、取值范围、精度或环境要求。
- **例**：一个最小可算的例子。
- **易错**：最常搞错的地方。
- **相关**：同主题的其他条目。
```

## 字段规则

| 字段 | 必填 | 写法 |
| --- | --- | --- |
| 标题 | 是 | 名词或名词短语，6–16 字，不用「关于…」「浅谈…」；人名命名的定理/效应/准则在标题末尾括号注英文原名，如「冯·米塞斯等效应力（von Mises equivalent stress）」 |
| 首段 | 是 | 定义/结论，1–3 句；不引用对话、不写「上面说到」 |
| 公式 | 有则写 | 独立成行 `$$...$$`；行内用 `$...$` |
| **符号** | 有公式必填 | 一行一个符号：记号 —— 含义；单位；必要时给取值范围 |
| **条件** | 有前提必填 | 定义域、假设、近似程度、环境条件；禁止「一般情况下」 |
| **例** | 可选 | 能算出数的最小例子，一两行 |
| **易错** | 可选 | 真实易混点，不写「注意安全」这类废话 |
| **相关** | 可选 | 同文件写条目名；跨文件写「文件名 › 标题」 |

标题层级：条目是所在主题的下一级；有条目名就够了，不要再套「概述」「简介」这种二级壳。

## 范例 1 · 数学

```markdown
### 贝叶斯公式
在已知 $B$ 发生的条件下，$A$ 的条件概率可由 $A$ 的先验概率与似然修正得到。

$$
P(A\mid B)=\frac{P(B\mid A)\,P(A)}{P(B)}
$$

- **符号**：$P(A)$ —— 先验概率；$P(B\mid A)$ —— 似然，$A$ 成立时观察到 $B$ 的概率；$P(A\mid B)$ —— 后验概率；$P(B)$ —— 归一化常数，$P(B)>0$。
- **条件**：$P(B)>0$；$A$ 与 $B$ 是同一概率空间里的事件。
- **例**：患病率 $1\%$、检出率 $99\%$、误报率 $5\%$ 时，阳性者真患病概率约 $16.7\%$。
- **易错**：$P(A\mid B)\ne P(B\mid A)$，把两者混用即「检察官谬误」。
- **相关**：全概率公式；条件独立。
```

## 范例 2 · 工程

```markdown
### 时间复杂度的大 O 记号
描述算法运行时间随输入规模增长的**上界**，忽略常数因子和低阶项。

$$
T(n)=O\bigl(f(n)\bigr)\iff \exists\,c>0,\ n_0,\ \forall n>n_0:\ 0\le T(n)\le c\,f(n)
$$

- **符号**：$T(n)$ —— 输入规模为 $n$ 时的基本操作次数；$f(n)$ —— 参照函数；$c$ —— 正常数因子；$n_0$ —— 起始规模。
- **条件**：只对 $n\to\infty$ 的渐进行为有意义，小规模时实测可能相反。
- **例**：二分查找每步折半，$T(n)=O(\log n)$。
- **易错**：$O$ 是上界不是精确值，$O(2n)$、$O(n+100)$ 都写作 $O(n)$；空间复杂度要另算。
- **相关**：大 $\Omega$、大 $\Theta$；摊还分析。
```

## 范例 3 · 生活

```markdown
### 冰箱冷藏与冷冻温度
冷藏室抑制多数细菌繁殖的温度带是 $0\text{–}4\ \mathrm{^\circ C}$，冷冻室应低于 $-18\ \mathrm{^\circ C}$。

- **符号**：$\mathrm{^\circ C}$ —— 摄氏度。
- **条件**：家用直冷/风冷冰箱；夏季环境温度高时需下调档位，开门频繁会使箱温回升。
- **例**：冷藏室放中部温度计，稳定后读数应 $\le 4\ \mathrm{^\circ C}$；冷冻室放冰淇淋 24 h 不软塌即达标。
- **易错**：门架是全箱最热的位置，牛奶、鸡蛋别长期放那儿；热菜可分装后放入，但一次别塞满。
- **相关**：食物冷藏保存期限；冷冻肉类解冻方式。
```

## 反例与问题清单

```markdown
#### 欧姆定律
电压等于电流乘电阻，公式 U=IR，一般情况下都适用，很重要。

- 符号：U 是电压
```

问题：

1. 公式没进 LaTeX，$U=IR$ 应写成 `$U=IR$`
2. 符号只解释了一个，$I$、$R$ 没说明，也没单位
3. 「一般情况下都适用」是空话——真实条件是「线性电阻、温度变化可忽略、稳态」
4. 没有说 $U$ 是电压降及其正方向约定
5. 首段是口语，不是定义

修正后：

```markdown
#### 欧姆定律
线性电阻两端电压与通过它的电流成正比，比例系数即电阻。

$$
U=IR
$$

- **符号**：$U$ —— 电阻两端电压降，单位 $\mathrm{V}$；$I$ —— 通过电阻的电流，单位 $\mathrm{A}$；$R$ —— 电阻，单位 $\Omega$。
- **条件**：线性（欧姆）电阻、稳态、温度变化可忽略；非线性元件只在工作点附近近似成立。
- **例**：$R=220\ \Omega$、$I=0.1\ \mathrm{A}$ 时 $U=22\ \mathrm{V}$。
- **易错**：$U$ 取电压降方向，与电流方向一致时为正；把电源电动势直接当 $U$ 会漏掉内阻分压。
```

## 三种常用变体

**步骤类**（操作流程）：把过程写成有序列表，每步一行，不塞进一句话。

```markdown
- **步骤**：
  1. 关闭进水阀，排空管内余水；
  2. 用扳手拆下软管，检查密封圈；
  3. 换新密封圈后先手拧，再上扳手半圈。
```

**对比类**（两个概念容易混）：用一张三列表，比成段文字清楚。

```markdown
| 项目 | 2.4 GHz | 5 GHz |
| --- | --- | --- |
| 穿墙能力 | 强 | 弱 |
| 理论速率 | 低 | 高 |
| 干扰 | 多（蓝牙、微波炉） | 少 |
```

**参数类**（一组数值/规格）：用表格列出「参数 | 数值 | 说明」，别写成散文。
